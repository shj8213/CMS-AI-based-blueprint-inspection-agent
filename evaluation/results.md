# 누락 탐지 시험 진행 기록

## 현재 기록

**2026-11-08에 실제 Copilot Studio 도면 검토 에이전트 시험을 진행했어요.** 사용자가 전체 응답과 결과 분류의 대조를 완료했다고 확인했어요. 부가 JSON 전문은 Studio 대화에만 있으며 이 작업 폴더에는 옮기지 않았어요. 아래는 사용자의 대조를 기록한 결과예요. 문서는 아직 팀과 공유하지 않았어요.

| 도면 | 찾은 누락 | 놓친 누락 | 잘못 지적한 항목 |
|---|---|---|---|
| D017 | MATERIAL 칸의 재질 값 누락 1건 | 시험 전 정답 대비 없음 | 확정 항목 없음 |
| D042 | 없음 | 시험 전 정답 대비 없음 | 확정 항목 없음 |

### 사전 정답과 시험 방식

- **사전 정답:** 사용자는 시험 전에 D017의 MATERIAL 값이 비어 있고 D042에는 누락이 없다고 알려 줬어요(2026-11-08 20:08 KST). 이 기록은 [평가자 정답 파일](trial-01/evaluator-only/answers.json)에 보존했어요. 이는 시험 전 정답 기록이며, 시험 후 결과 분류의 전체 검토나 승인을 뜻하지 않아요.
- **정답 미전달:** 도면마다 새 대화에서 해당 PDF 하나와 `request.txt`만 전달했어요(D017 20:14, D042 20:18 KST). 정답·누락 종류·검사 목록은 에이전트에 전달하지 않았어요.
- **입력 방식:** ② 분석 결과 없이 ③ 도면 검토 에이전트에 PDF를 직접 첨부했어요.
- **표 해석:** 놓친 누락은 시험 전에 기록한 정답과의 비교예요. D017은 해당 재질 누락을 찾았고, D042의 사전 정답에는 누락이 없어요. 이는 두 도면에 다른 실제 누락이 없다는 보증은 아니에요. 오탐으로 확정한 지적은 없어요.

### 별도 판단 보류

- D017의 치수 공차 또는 일반 공차 주서 지적은 보류예요. 사전 정답에 없다는 이유만으로 실제 누락이 아닌 오탐이라고 확정하지 않았어요.
- D042의 치수 공차 및 알루미늄 합금 종류 지적도 각각 보류예요. 사전 정답에 없다는 이유만으로 오탐이라고 확정하지 않았고, 실제 누락 여부도 확정하지 않았어요.
- D042의 도면 번호·개정·척도·투상법은 에이전트가 “확인 필요”로 언급했어요. 누락이나 오탐으로 집계하지 않고 별도 보류로 남겨요.

### 기록 범위와 남은 확인

도면별 응답 본문은 [시험 보고서 초안](trial-01-report.md)에 옮겼어요. 각 응답 끝의 부가 JSON 전문은 Studio 대화에만 보존되어 있고, 이 작업 폴더에 전문을 옮기지 않았어요. 따라서 원문 전체가 옮겨졌다고 볼 수 없어요.

`results.json`의 `human_reviewed`는 사용자의 대조 확인에 따라 `true`예요. 다만 부가 JSON 전문은 Studio 대화에만 있어 저장소 문서에 옮기지 않았어요. 현재 보고서와 진행 기록은 수동 정리본이며 아직 팀과 공유하지 않았어요. #34의 팀 공유 조건은 남아 있어요.
