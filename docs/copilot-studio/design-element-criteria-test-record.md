# 기계설계요소 기준 자료 시험 기록 (양식)

관련 이슈: [#50](https://github.com/shj8213/CMS-AI-based-blueprint-inspection-agent/issues/50)

[design-element-criteria.md](design-element-criteria.md)를 Copilot Studio ③ 에이전트 지식에 올린 뒤, 아래 질문으로 자료를 근거로 답하는지 사람이 확인하고 기록하는 양식입니다. **에이전트 답변과 사람 확인 칸은 비워 두었습니다. 업로드와 시험은 사람이 직접 한 뒤 채웁니다.**

시험에는 개인정보나 실제 기밀이 없는 예제만 사용합니다. 이 기록은 정확도 보증이 아닙니다.

## 시험 기록

| # | 질문 | 기대하는 방향(참고) | 에이전트 답변 | 자료를 근거로 했는가 | 사람 확인 결과 | 메모 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 베어링이 들어가는 축 부분에는 무엇이 필요해? | 자리 지름·공차, 표면 거칠기, 어깨와 모서리 처리 | | | | |
| 2 | 키로 기어를 고정하는 축에는 어떤 정보가 있어야 해? | 키홈 폭·깊이·길이·위치 | | | | |
| 3 | 나사 구멍이 있는 부품 도면에서 확인할 것은? | 나사 호칭, 깊이, 밑구멍 | | | | |
| 4 | 맞물리는 부품이 없는 단순 판재 도면에 공차 누락을 지적해야 해? | 일반 공차로 충분하면 지적하지 않음 (#34 사례) | | | | |
| 5 | 재질이 표제란에 있는 도면에 합금 종류 누락을 지적해야 해? | 추측해서 지적하지 않음 (#34 사례) | | | | |

## 확인 기준

- "자료를 근거로 했는가": 답변이 이 문서의 항목 내용과 맞는지 확인합니다.
- 4·5번은 불필요한 지적을 하지 않는지 확인합니다.
- 자료에 없는 내용을 지어내거나 규격 번호를 단정하면 메모에 적습니다.
