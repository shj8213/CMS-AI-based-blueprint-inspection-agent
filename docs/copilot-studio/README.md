# Copilot Studio 도면 검토 에이전트 시험 자료

관련 이슈: [#31 — Copilot Studio에서 도면 누락을 찾는 시험용 에이전트 만들기](https://github.com/shj8213/CMS-AI-based-blueprint-inspection-agent/issues/31)

**이 자료는 시험용 에이전트의 지침과 가상 입력 시험 기록입니다. 완성된 제품이나 모든 누락을 찾는다는 보증이 아닙니다.** 학생의 도면 직접 대조가 남아 있어 이슈 완료 근거로 대신 사용할 수 없습니다.

## 포함한 자료와 현재 상태

| 파일 | 용도 |
| --- | --- |
| [reviewer-instructions-v2.txt](reviewer-instructions-v2.txt) | ③ 도면 검토 에이전트에 저장한 V2 지침 원문 |
| [examples/reviewer-v2-probe-input.json](examples/reviewer-v2-probe-input.json) | 사람이 만든 가상의 ② 분석 결과. 실제 도면이나 실제 ② 실행 결과가 아님 |
| [examples/reviewer-v2-probe-result.json](examples/reviewer-v2-probe-result.json) | 위 입력에 대한 Studio 미리 보기의 실제 응답. 기대 정답이나 매번 같은 출력이라는 뜻이 아님 |

2026-11-02 시험 시점에 기존 V1은 게시된 상태였고, V2는 **저장만 된 미게시 초안**이었습니다. V2를 저장한 뒤 새로고침하여 지침 내용이 유지되는 것을 확인했습니다. 이 파일들을 Git에 추가해도 Studio에 자동 반영되거나 게시되지 않습니다. Studio의 전체 에이전트 내보내기 파일도 아닙니다.

실제 도면·PDF·화면 캡처·실제 도면 검토 원문, 계정·환경·에이전트 식별자와 인증 정보는 포함하지 않았습니다. 가상 입력과 응답에 나오는 치수·재질은 실제 설계 자료가 아닙니다.

## 에이전트가 하는 일

도면 또는 ②의 읽기 자료를 근거로 필요한 정보를 스스로 도출합니다. 사람이 검사 목록이나 정답을 미리 알려 주는 방식이 아닙니다. `누락 후보`, `확인 필요`, `판독·연결 확인`을 구분하고, 각 판단의 위치·근거·한계·다음 확인 방법을 설명합니다.

V2는 다음 동작을 보완합니다.

- 작은 영역을 보지 못한 채 페이지 전체를 검토 완료로 처리하지 않습니다.
- 표의 행 제목과 실제 같은 행 값을 유지하며 계산값으로 원문을 고치지 않습니다.
- 품번이 건너뛴 것만으로 누락을 지적하지 않습니다.
- 치수의 대상이나 문자가 불확실하면 누락 또는 정상으로 확정하지 않습니다.
- 후속 검토에서 기존 항목 ID와 해소·철회 이유를 남깁니다.
- 사람 확인 상태는 항상 `미확인`으로 남깁니다.

웹사이트 자동 연결, ②→③ 자동 호출, 도면 수정·설계 승인·규격 적합성 인증은 구현 범위가 아닙니다. 저장소 홈페이지의 **도면 읽기**와 Studio의 **검토**는 별개입니다.

## Studio에서 가상 자료 시험을 재현하는 방법

이 순서는 승인된 Studio 환경과 에이전트 편집·시험 권한이 있는 팀원을 위한 안내입니다. 접근할 수 없으면 관리자에게 요청하고, 인증이나 권한을 우회하지 않습니다. 이 가상 자료도 Studio에 전송되며 사용량이 발생할 수 있습니다.

1. Studio에서 팀의 `도면 검토 에이전트`를 열고 빌드 화면의 지침을 확인합니다. 이미 다른 작업으로 수정된 지침은 덮어쓰지 말고 담당자와 먼저 확인합니다.
2. 적용이 승인된 초안에 `reviewer-instructions-v2.txt` 전체를 넣고 저장합니다. 게시하지 않습니다. 지침 끝 개행을 제외하면 6,312자이며, 저장 후 다시 열어 같은 내용인지 확인합니다.
3. 시험 당시에는 장기 메모리·웹 검색·조직 문서 검색·자동 에이전트 연결을 사용하지 않았고 Microsoft 인증을 유지했습니다. 재현을 위해 인증·권한·게시 설정을 임의로 바꾸지 않습니다. 도구의 종류와 사용 한도는 환경에 따라 다를 수 있습니다.
4. 미리 보기에서 **새 채팅**을 엽니다. 이전 도면이나 답이 남은 대화를 이어 쓰지 않습니다.
5. 아래 요청문 뒤에 `examples/reviewer-v2-probe-input.json`의 전체 내용만 붙여 보냅니다. 결과 파일, 아래 확인 표, 누락 목록이나 기대 정답은 보내지 않습니다. 이 시험에는 PDF·이미지를 첨부하지 않습니다.

   > 다음은 가상의 ② 형식 읽기 자료이며 원본 이미지/PDF는 제공하지 않았어. 이 자료를 검토하고 기존 구조의 JSON 하나만 출력해줘.

6. 응답이 끝나면 JSON 코드 블록을 별도 파일로 보존합니다. 저장소의 기존 응답을 새 결과로 덮어쓰지 않습니다. 문장·ID·개수가 완전히 같아야 하는 시험은 아니며 아래 동작과 근거를 대조합니다.

## 가상 자료 시험 결과

2026-11-02 20:37:52~20:40:15(KST)에 저장된 V2 초안의 새 미리 보기 대화에서 **가상 JSON 1건**을 시험했습니다. 입력의 줄바꿈과 공백은 축약했으나 내용은 유지했고, 기대 답과 이전 도면 결과는 전달하지 않았습니다. 이번 PR 준비 중 Studio 시험을 새로 실행한 것은 아닙니다.

응답은 `부분 완료`, `판독·연결 확인` 3건, `누락 아님` 3건, `human_review_status: "미확인"`이었습니다. 아래는 에이전트가 응답 문장과 입력을 대조한 기록이며 학생 확인이 아닙니다.

| 확인 항목 | 관찰 결과 |
| --- | --- |
| 표의 원문과 계산을 구분하는가 | F01은 `모듈: 기어 치형`, `치형: 3`을 유지했습니다. 지름과 잇수의 계산이 맞아도 3을 모듈 행에 옮기거나 표를 정상 판정하지 않았습니다. |
| 품번의 비연속만으로 지적하지 않는가 | 품번 1·4를 이유로 만든 `findings`는 없었습니다. 다른 문서의 부품 유무는 판단하지 않았습니다. |
| 깊이 치수의 불확실한 연결을 보류하는가 | E06의 `깊이 7`을 F02 `판독·연결 확인`으로 남겼고 `not_missing`으로 확정하지 않았습니다. |
| 읽지 못한 문자를 임의로 고치지 않는가 | F03은 `Ø0?5` 원문을 유지했습니다. |
| 범위와 한계를 밝히는가 | 원본 미제공, 미검토 영역, 판독 미해결, 외부 정보 필요와 도구 한계를 명시했습니다. |
| 출력 구조와 참조가 일치하는가 | JSON 파싱, 필수 필드, ID 중복, 입력 요소 참조와 사람 미확인 상태 검사를 통과했습니다. |

응답은 브라우저의 코드 블록 복사 기능으로 보존했으며, 브라우저와 로컬 파일의 SHA-256이 일치했습니다. SHA-256은 같은 내용인지 확인하는 값이지 답이 정확하다는 증거는 아닙니다.

| 대상 | SHA-256 |
| --- | --- |
| V2 지침 — 끝 개행 제외 | `f692030500cf68824d06d566da960c3c094d01e0ea35ccfcf45b14038a082137` |
| 가상 시험 응답 원문 | `a49dd323b2333363f08b0e6f9c0a7a681e3e3c6513d01d1795f2d5560314dbbb` |

저장소 루트에서 아래 명령으로 두 JSON 파일의 문법을 확인할 수 있습니다. **저장된 파일을 검사할 뿐 Studio를 다시 실행하거나 의미의 정확도를 판정하지 않습니다.**

```sh
python3 -m json.tool docs/copilot-studio/examples/reviewer-v2-probe-input.json > /dev/null
python3 -m json.tool docs/copilot-studio/examples/reviewer-v2-probe-result.json > /dev/null
```

정상 종료하면 JSON 문법 검사를 통과한 것입니다. 오류가 있으면 출력된 오류를 해결해야 합니다. 홈페이지의 기존 DXF·PDF 읽기 검사 방법은 [저장소 안내](../../README.md#예제와-자동-검사)에 있으며, 이 Studio 가상 자료 시험과는 별개입니다.

## 이슈 완료 조건과 남은 범위

기존 V1에서 직접 제작한 축 도면의 누락본·정상 비교본을 시험한 기록은 [이슈의 완료 준비 댓글](https://github.com/shj8213/CMS-AI-based-blueprint-inspection-agent/issues/31#issuecomment-6575165231)에 있습니다. 그 시험에서는 원본 도면과 같은 도면의 ② JSON을 수동으로 전달했습니다. 그 기록을 V2 실제 도면 재시험으로 취급하지 않습니다.

| #31 완료 조건 | 현재 상태와 근거 |
| --- | --- |
| Studio 테스트 대화에서 예제 도면 전달·검토 요청 | 기존 V1 시험에서 확인한 기록이 있습니다. 이 PR의 가상 JSON 시험은 도면 파일 전달 시험이 아닙니다. |
| 빠진 정보와 판단 근거 설명 | 기존 V1 누락본에서 누락 후보와 이유를 제시했고, 학생이 도면과 대조해 맞는 지적임을 확인했습니다. |
| 빠진 부분을 미리 알려주지 않음 | 기존 시험 기록과 이번 가상 시험 모두 정답표·누락 목록을 입력하지 않았습니다. |
| 불확실한 부분을 확인 대상으로 구분 | 기존 기록 및 이번 V2 가상 응답에서 확인했습니다. |
| 사람이 실제 도면과 설명을 직접 비교 | 2026-11-02 학생이 V1 누락본 축 도면과 검토 설명을 6개 항목으로 대조했습니다. 결과는 [대조 기록 댓글](https://github.com/shj8213/CMS-AI-based-blueprint-inspection-agent/issues/31#issuecomment-6578837902)에 있습니다. |
| 개인정보·기밀 없는 예제 사용 | 기존 기록은 직접 제작한 예제, 이번 공개 자료는 가상의 읽기 자료입니다. 실제 도면은 이 PR에 포함하지 않습니다. |

사람 대조는 V1 시험 결과를 대상으로 했습니다. 이 PR의 V2 가상 JSON 응답을 실제 도면과 대조한 것은 아닙니다.

다음 항목은 미검증 또는 제외 범위로 남아 있으며, 정확도 확인은 #34, 여러 페이지·스캔 PDF는 #32, DXF는 #33에서 이어갑니다.

- V2로 이미지·PDF를 첨부한 독립적인 새 대화 시험, 실제 도면 판독 정확도와 모든 누락의 검출률.
- 다양한 도면과 반복 요청에서의 일관성, 도구 한도·출력 중단 문제의 완전한 해결.
- V2의 실제 도면 후속 검토에서 항목 ID 유지·철회·해소 동작.
- 웹 연결, 인증 설정 변경, V2 게시. 이 자료 정리 과정에서 수행하지 않았습니다.
