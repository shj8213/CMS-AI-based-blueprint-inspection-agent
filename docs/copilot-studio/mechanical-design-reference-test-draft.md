# 기계설계요소 기준 자료 시험 초안

> **상태:** 질문 초안과 사람 확인용 기준표입니다. Studio에 확장 초안 텍스트를 연결해 구멍·나사·기어 질문과 연습 도면을 시험했습니다. 사용자가 세 질문의 답변을 직접 비교했다고 확인했습니다. 아래 질문별 표에는 개별 대조 결과를 기록하지 않았습니다.
>
> 이 문서는 시험 진행자용입니다. **Studio 지식으로 올리거나 에이전트에게 보내지 마세요.** 에이전트에는 시험 질문만 보내고, 아래 대조 기준은 사람만 사용합니다.

## 시험 대상과 주의

- 기준 자료 초안: [기계설계요소 도면 검토 기준 자료](mechanical-design-reference-draft.md) 및 [전산응용기계제도 확장 초안](mechanical-drawing-reference-expanded.txt)
- 질문 5~8은 확장 초안을 등록한 상태에서 시험합니다. 팀의 내용·출처 검토는 아직 필요합니다.
- 이 시험은 기준 자료를 지식으로 찾고, 쉬운 말로 정확히 설명하는지 확인합니다. 도면 파일은 보내지 않습니다.
- 승인된 Copilot Studio 환경에서 담당자가 기준 자료를 지식에 올리고, 에이전트가 그 자료를 사용할 수 있는 상태인지 먼저 확인합니다. 이 저장소의 문서만 추가해도 Studio에 자동 반영되지는 않습니다.
- 사람 확인용 대조 기준은 에이전트에게 보내지 않습니다. 시험 질문은 한 번에 하나씩 새 대화에서 합니다.
- Studio에 올리거나 에이전트를 변경할 때는 담당자의 권한과 팀 승인을 확인합니다. 게시가 승인되지 않았다면 게시하지 않습니다.

## 진행 방법

1. 팀이 기준 자료 초안을 검토하고 승인할 내용을 정합니다. 출처와 적용 범위가 불확실한 기준은 확정된 규칙처럼 쓰지 않습니다.
2. 승인된 자료를 ③의 지식에 등록하고, 업로드가 완료되어 에이전트가 참조할 수 있는지 확인합니다. 확인할 수 없으면 시험을 진행하지 않습니다.
3. ③에서 아래 질문마다 새 대화를 엽니다. 질문 문장만 보내고, 지식 문서나 사람 확인용 대조표를 질문과 함께 붙여넣지 않습니다.
4. 각 답변을 별도로 기록하고 사람 확인용 대조 기준과 비교합니다. 에이전트 답변은 설계 승인이나 규격 적합성 판정이 아닙니다.

## 에이전트에 보낼 질문

다음 질문을 하나씩 새 대화에 보냅니다. 아래 표와 기록 양식은 시험 진행자만 보고, 에이전트에는 보내지 않습니다.

### 질문 1 — 베어링 자리

> 베어링이 들어가는 축 부분을 도면에 표시할 때 어떤 정보를 확인해야 해? 베어링 종류나 하중 같은 정보가 없으면 무엇을 정할 수 없는지도 쉬운 말로 설명해줘.

### 질문 2 — 나사와 키홈

> 나사와 키홈이 있는 부품을 제작하고 조립하려면 도면에서 무엇을 확인해야 해? 상대 부품 정보가 없을 때 임의로 정하면 안 되는 내용도 알려줘.

### 질문 3 — 공차·끼워맞춤

> 일반 공차가 적혀 있으면 축과 베어링의 끼워맞춤도 정해진 거야? 어떤 근거가 있어야 판단할 수 있는지, 정보가 부족할 때는 어떻게 말해야 하는지 설명해줘.

### 질문 4 — 표면·재질·표제란

> 모든 도면에 표면 거칠기와 열처리 값을 꼭 적어야 해? 언제 필요한지와, 부품의 용도나 사용 조건을 모를 때 단정하면 안 되는 점을 설명해줘.

### 질문 5 — 기어

> 기어 도면과 요목표에서 무엇을 확인해야 해? 요목표의 행과 값이 잘 안 맞아 보이면 어떻게 판단해야 해?

### 질문 6 — 구멍과 나사

> 막힌 나사 구멍과 머리가 들어가는 단이 있는 구멍을 볼 때, 각각 어떤 표시와 깊이를 확인해야 해? 정보가 없으면 어떻게 해야 해?

### 질문 7 — 조립도와 부품표

> 조립도에서 품번이 1, 4 순서로 나타나면 중간 부품이 빠졌다고 판단해도 돼? 무엇을 더 확인해야 해?

### 질문 8 — 스프링과 용접

> 스프링과 용접부가 있는 도면을 볼 때 어떤 내용을 확인해야 해? 도면에 크기나 사용 조건이 없으면 어떻게 말해야 해?

## 사람 확인용 대조 기준

아래 내용은 에이전트에게 보내지 않습니다. 기준 자료에 있는 설명과 답변을 사람이 비교합니다. 쉬운 표현은 달라도 의미가 같으면 인정하고, 질문에 없는 요구나 구체 값을 만들어 냈는지도 확인합니다.

| 질문 | 기준 자료에 근거해 포함해야 할 설명 | 근거 없이 단정하지 않아야 할 내용 |
|---|---|---|
| 1. 베어링 자리 | 베어링 자리의 지름·길이, 기능에 필요한 공차나 끼워맞춤, 어깨·축 방향 고정과 조립 정보 등을 살펴본다고 설명하는지. 표면 상태는 기능에 중요할 때 확인한다고 하는지 | 베어링 종류·하중·회전 조건·상대 부품을 모른 채 특정 끼워맞춤 등급, 어깨 치수, 고정 방식이나 값을 지정하지 않는지 |
| 2. 나사와 키홈 | 나사 종류·호칭·위치·개수와 필요 시 피치·등급·방향·길이/깊이, 키홈의 형상·크기·위치·방향, 상대 부품 및 조립 관계를 확인한다고 하는지 | 체결 목적·상대 부품 정보 없이 나사 등급·방향·구멍 상태, 키 규격·치수·토크를 지어내지 않는지 |
| 3. 공차·끼워맞춤 | 일반 공차가 적용되는 범위를 확인하고, 기능상 필요한 축·구멍 끼워맞춤은 별도 근거와 상대 부품 정보가 필요할 수 있다고 설명하는지 | 일반 공차만으로 기능상 끼워맞춤이 자동 결정된다고 하거나 특정 공차 값을 제안하지 않는지 |
| 4. 표면·재질·표제란 | 표면 거칠기는 마찰·밀봉·움직임·접촉 등 기능에 따라 살펴보고, 재질·열처리는 사용 조건과 검사 기준에 따라 확인한다고 설명하는지. 표제란은 식별·단위·투상·개정 정보 확인에 쓰인다고 하는지 | 모든 표면에 같은 거칠기나 모든 부품에 열처리가 필요하다고 하거나, 재질 등급·경도·열처리 값을 임의로 정하지 않는지 |
| 5. 기어 | 종류, 이의 개수, 표에 적힌 치수와 요목표의 행·값 대응 및 상대 기어를 확인하는지 | 값이 어긋나면 판독·연결 확인으로 남기고, 규격과 전제 없이 계산으로 값을 채우지 않는지 |
| 6. 구멍과 나사 | 막힌 나사 구멍의 나사 깊이와 기초 구멍 깊이를 구분하고 단이 있는 구멍의 지름·깊이를 확인하는지 | 표시가 불명확한 상태에서 나사 종류나 깊이를 만들어 내지 않는지 |
| 7. 조립도와 부품표 | 품번 표시와 부품표의 해당 행, 수량·조립 관계를 대조하는지 | 품번이 연속하지 않는 것만으로 누락된 부품이 있다고 단정하지 않는지 |
| 8. 스프링과 용접 | 표시된 스프링 형상·치수·끝 모양과 용접 기호·대상·실제 표기된 크기 등을 확인하는지 | 조건 없이 스프링 하중이나 용접 크기를 정하거나 안전성을 인증하지 않는지 |
