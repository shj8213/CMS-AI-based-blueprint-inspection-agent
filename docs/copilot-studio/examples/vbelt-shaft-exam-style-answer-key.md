| 줄 | 뜻 |
| --- | --- |
| `Ø17 k6 : 베어링 6203 (왼쪽·오른쪽)` | 양쪽 베어링 자리 |
| `Ø16 : 오일실 (오른쪽 커버 안)` | 오일실이 닿는 자리(끼워맞춤 기호 없음) |

| `키홈 깊이 11` | 단면 A-A에 적힌 깊이 값 |
| `기하공차 : 풀리 자리 원주 흔들림` | 도면에 공차 값(.02 같은 글자)이 있어야 함 |
| `축 전체 길이 123` | 17k6 13 + Ø22 44 + 17k6 13 + Ø16 15 + 14h6 24 + M12 14 |

## 비교 도면에 넣은 틀린 곳

1. **몸통 길이:** Ø22 구간이 44로 그려졌는데 치수는 `42`입니다. 직렬 합계가 121이 되어 전체 123과 맞지 않습니다.
2. **풀리 자리 끼워맞춤:** 문제지는 `h6`인데 도면은 `Ø14k6`입니다.
3. **단면 A-A의 키홈 폭:** `6N9`로 적었지만 그려진 폭과 문제지는 5입니다.
4. **오일실 자리 표면 거칠기:** Ø16 구간의 거칠기 기호(`y`)를 뺐습니다.
5. **키홈 깊이:** 단면 A-A에 `12`로 적었는데 문제지는 11입니다.
6. **기하공차 빠짐:** 풀리 자리 원주 흔들림 공차 틀을 뺐습니다.

## 홈페이지 코드 점검 결과 (2026-11-15)

| 도면 | 결과 |
| --- | --- |
| 기준 도면 | 틀림 0건, 확인 필요 0건, 질문 2개(Ø17k6·Ø14h6 부품) |
| 기준 도면 + 문제지 | 틀림 0건, 확인 필요 0건, 질문 0개. 거칠기 4구간 모두 "이미 확인된 정보" |
| 비교 도면 | 1번(틀림, 그려진 길이로 `42`를 가리킴), 3번(틀림, `6N9` ≠ 그려진 폭 약 5), 확인 필요 1건(`k6`가 Ø17·Ø14 두 지름에 쓰임). 2번은 문제지 없이는 확정 못 하고, 4번은 찾지 못함 |
| 비교 도면 + 문제지 | 6개 모두: 1·3·5번 틀림, 2번 틀림(`h6` ≠ `k6`), 4번·6번 확인 필요(거칠기 없음, 공차 값 없음). 문제지로 부품을 알게 된 구간의 질문은 하지 않음 |

- 1번: 가로 치수들의 "선 길이 ÷ 숫자"가 가장 많이 서로 맞는 묶음으로 축척을 구하고, 직렬 치수 중 그려진 길이와 숫자가 다른 치수가 하나뿐이면 그 치수를 가리켜요. 축척을 무시하고 그린 도면이면 틀릴 수 있어요.
- 4번: 문제지에 적힌 부품 자리마다 `w`·`x`·`y`·`z` 거칠기 글자가 그 구간 위아래 약 25mm 안에 있는지 봐요. 거칠기 기호를 그림으로만 그렸으면 찾지 못해요.
- 5번: N9/P9 글자 근처(약 25mm)의 숫자를 깊이로 읽는 추정이에요. 6번: 도면에 `.02` 같은 공차 값 글자가 하나도 없을 때만 알려요(값이 맞는지, 어느 면에 걸렸는지는 안 봐요). 거칠기 표준 값(0.8 등)은 공차 값으로 치지 않아요.
- 세로 치수, 조립도 그림, KS 적합성은 코드로 보지 않아요.
