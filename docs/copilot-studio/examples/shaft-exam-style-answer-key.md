# 기능사 양식 축 연습 도면 정답표

> **시험 전에는 에이전트에 보내지 마세요.** 이 문서는 사람이 결과를 확인할 때만 사용합니다.

전산응용기계제도기능사 도면에서 흔히 쓰는 양식을 따라 새로 그린 가상 연습 도면입니다. 양식은 3각법, 표제란·부품표, 주서, 끼워맞춤, 원주 흔들림 공차, 표면 거칠기 기호, 양 끝이 반원인 키홈, 단면 A-A입니다. 실제 기출 도면이나 공개 도면을 옮기지 않았습니다. 그리고 KS 적합성, 설계 적절성, 제작 가능성은 확인하지 않았습니다.

- `tests/fixtures/shaft-exam-style-reference.pdf`: 표기가 서로 맞는 기준 도면
- `tests/fixtures/shaft-exam-style-challenge.pdf`: 일부러 틀린 곳 3개를 넣은 비교 도면
- 원본: `tools/practice-drawings/shaft-exam-style.html`
- PDF 다시 만들기: `python3 tools/make_exam_style_drawings.py` (Chrome 필요)

## 비교 도면에 넣은 틀린 곳

1. **전체 길이:** 직렬 치수 합계는 `18 + 12 + 45 + 18 + 25 = 118`인데 전체 치수는 `120`입니다.
2. **단면 A-A의 키홈 폭:** 단면 치수는 `8N9`인데, 정면도와 단면에 그려진 키홈 폭은 6입니다(기준 도면은 `6N9`).
3. **없는 데이텀 참조:** 원주 흔들림 공차가 `A-C`를 기준으로 삼지만, 도면에는 데이텀 A와 B만 있습니다(기준 도면은 `A-B`).

## 홈페이지 코드 점검 결과 (2026-11-15)

| 도면 | 결과 |
| --- | --- |
| 기준 도면 | 틀림 0건, 확인 필요 0건(잘못 찾은 것 없음) |
| 비교 도면 | 틀림 3건: 1번(전체 길이 120 ≠ 118), 2번(`8N9` ≠ 그려진 폭 약 6), 3번(데이텀 C 없음) |
| 기준 도면 + 문제지 | 틀림 0건, 확인 필요 0건 |
| 비교 도면 + 문제지 | 틀림 3건(중복 없음), 1·2번 카드에 문제지 근거가 함께 붙음 |

- 2번은 가로 치수로 도면 축척을 구한 뒤, `N9`·`P9`가 붙은 숫자 근처의 세로선 두 개 간격과 비교해 찾습니다. `N9`·`P9` 숫자를 키홈 폭으로 보는 것은 가정입니다.
- 3번은 네모 칸 안의 글자 하나를 데이텀으로 보고, 공차에 적힌 데이텀 글자가 모두 있는지 확인해 찾습니다. 데이텀 기호가 그림(이미지)이면 찾지 못합니다.
- 문제지: `tests/fixtures/shaft-exam-problem-sheet.pdf` (원본 `tools/practice-drawings/shaft-exam-problem-sheet.html`). 가상 문제지이며 "조립 정보" 표의 글자만 코드로 비교합니다. 조립도 그림은 해석하지 않습니다.
