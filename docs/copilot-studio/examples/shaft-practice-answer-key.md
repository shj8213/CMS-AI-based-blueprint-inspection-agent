# 축 도면 연습 정답표

> **시험 전에는 에이전트에 보내지 마세요.** 이 문서는 기준을 사람이 확인할 때만 사용합니다.

홈페이지의 축 분석 연습에는 서로 다른 목적의 PDF 두 개가 있습니다.

- `tests/fixtures/shaft-practice-reference.pdf`: 일관된 가상 기준 도면
- `tests/fixtures/shaft-practice-challenge.pdf`: 기준 도면의 표기 일부를 바꾼 비교 도면

비교 도면에 의도적으로 넣은 불일치는 세 가지입니다.

1. **전체 길이:** 구간 치수 `25 + 40 + 55 + 30 + 10 = 160 mm`와 전체 치수 `165 mm`가 맞지 않습니다.
2. **베어링 끼워맞춤부:** 도면의 기준 주기는 `⌀25 k6`인데 해당 구간 치수는 `⌀28 k6`로 표시되어 서로 다릅니다.
3. **키홈 폭:** 단면 치수와 키홈 설명은 `8 mm`인데 별도 주기는 키홈 폭을 `10 mm`로 적었습니다.

나머지 표기는 연습용으로만 만든 가상 내용입니다. 도면은 실제 기출 문제를 복사하지 않았으며, 규격 적합성·설계 적절성·제조 가능성을 확인하거나 보증하지 않습니다. 이 정답표는 정적 홈페이지 빌드에 포함하지 않습니다.

## 권장 시험 순서

1. 먼저 `shaft-practice-challenge.pdf`만 ② 또는 검토 기능에 제공하고, 정답표는 보내지 않습니다.
2. 응답을 받은 뒤 위 세 항목을 각각 찾았는지, 근거가 도면에 있는지 기록합니다.
3. 같은 조건에서 `shaft-practice-reference.pdf`도 확인해 정상 표기를 오류라고 잘못 지적하는지 살펴봅니다.
4. 사람이 두 PDF와 응답을 직접 대조합니다. 자동 검사나 에이전트 결과는 사람 확인을 대신하지 않습니다.
