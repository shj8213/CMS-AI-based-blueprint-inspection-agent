또는 버튼을 눌러 파일을 선택할 수 있어요

파일은 서버로 보내지 않고 이 브라우저 안에서만 읽어요. 스캔 PDF의 글자는 OCR로 찾으며, 인식 결과는 원본과 비교해 주세요. 채팅은 직접 열 때만 Microsoft에 접속하며, 복사한 내용을 사용자가 붙여넣어 전송할 때 외부에서 처리해요.

확인용 예제 받기: DXF · 일반 PDF · 스캔 PDF

도면 판독 결과는 설계 적합성 판정이 아니에요. 채팅 답변은 원본과 비교하고 사람이 검토해야 해요. 가공방법 추천·수정본 제작은 아직 홈페이지 기능으로 연결되지 않았어요.

    도면 분석 에이전트에게 직접 전달하기

    1. 아래 전체 결과를 펼쳐 글자·경고에 개인정보, 고객명, 회사의 비공개 도면 정보가 없는지 확인하세요.
    2. 민감한 내용 확인란을 체크하고 전체 결과 복사를 누르세요.
    3. 채팅 열기를 누른 뒤, 사용자가 채팅 입력창에 직접 붙여넣고 전송하세요. 자동 전송하지 않아요.

    채팅을 열면 Microsoft에 접속해요. 로그인 없이 쓰는 공개 채팅이며, 사용량에 따라 운영자의 Copilot Studio 크레딧이 소모되거나 비용이 발생할 수 있어요. 붙여넣어 전송한 도면 정보는 Microsoft에서 처리돼요. 원본 파일은 자동으로 보내지지 않으며, 이 채팅에서는 파일 첨부도 지원하지 않아요.

    현재 표시 페이지나 목록 일부가 아니라 전체 페이지·요소·경고를 JSON(구조화된 텍스트)으로 복사해요. 파일명은 포함하지 않지만 도면 속 글자에는 민감한 내용이 남을 수 있어요. 민감한 정보가 있으면 전송하지 말고, 공개 가능한 도면으로 다시 읽어 주세요. OCR 신뢰도와 확인 필요 후보도 그대로 담으며, 도면 판독 결과는 설계 적합성 판정이 아니에요.

    1. 복사할 전체 결과와 민감한 내용 확인

    자동 복사가 실패하면 전체 텍스트를 선택하고 Windows는 Ctrl+C, macOS는 Command+C로 직접 복사하세요. 모바일에서는 글자를 길게 눌러 전체 선택 후 복사하세요. 직접 복사를 마친 경우에만 아래 확인 버튼을 누르세요.

    Copilot Studio 도면 분석 채팅

    입력창에 복사한 JSON을 직접 붙여넣고 전송하세요. 홈페이지는 메시지나 원본 파일을 자동으로 보내지 않으며, 채팅 답변을 표·미리보기에 자동 반영하지 않아요.

    홈페이지에서는 외부 채팅의 입력창·로그인 요구·응답 성공을 확인할 수 없어요. 채팅이 보이지 않으면 같은 채팅을 새 탭으로 열기를 사용하세요. 긴 JSON이 채팅 길이 제한에 걸리면 임의로 잘라 보내지 말고 관리자에게 알려 주세요.

    읽은 요소만 다시 그린 미리보기예요. 원본의 글꼴·정렬·잘림·숨김 표시는 반영하지 않아요. 노란 점선 원은 곡선에서 추정한 원이에요.
