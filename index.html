분석 시간은 도면에 따라 달라서 진행률은 예상값이에요.

공개 홈페이지의 자동 연결은 남용 방지를 위해 Cloudflare 확인 절차를 사용해요. 접속 정보가 Cloudflare로 전달되고, 필요하면 확인 창이 나타날 수 있어요.

도움말과 예제

도면 분석을 선택하면 PDF가 Microsoft에 전송되고 사용량이 발생할 수 있어요. 첨부 파일은 대화의 마지막 활동 이후 28일 동안 보관될 수 있어요. DXF는 PDF로 변환해 주세요.

‘이 브라우저에서만 읽기’를 선택하면 파일을 외부로 보내지 않아요. 스캔 PDF의 글자는 OCR로 찾으므로 원본과 비교해 주세요.

확인용 예제 받기: DXF · 일반 PDF · 스캔 PDF

검토 시험용 DXF 받기: 예제 A · 예제 B · 예제 C — 개인정보·기밀이 없는 가상 자료예요.

축 분석 연습: 기준 도면 · 비교 도면 — 비교 도면의 불일치를 먼저 찾고, 분석 후 정답표를 확인하세요.

현재 1차 시험은 단일 축 부품도를 중심으로 진행해요. 다른 종류 도면의 업로드를 막지는 않지만 축이라고 단정하지 않도록 안내해요. ‘도면 분석하기’는 PDF를 Microsoft 서비스에 보내요. 전송 권한이 있고 개인정보·기밀이 없는 도면만 사용해 주세요. 분석은 참고용이며 중요한 내용은 원본과 직접 비교해 주세요.

이미 받은 분석 결과가 있나요?

저장된 결과

분석이 끝난 결과는 이 컴퓨터의 브라우저에 자동 저장돼요. 다시 기다리지 않고 바로 열 수 있어요.

    저장된 결과는 외부로 보내지 않지만, 이 브라우저를 쓰는 사람은 볼 수 있어요. 필요 없으면 삭제해 주세요. 최근 20개까지 보관해요.

    ② 학습용 참고 예제 결과를 도면과 직접 비교해 맞으면 확인 완료를 체크하세요. 체크한 결과만 모아 파일로 내려받고, 그 파일을 Copilot Studio ②의 지식에 올리면 다음 분석 때 읽는 방식을 참고해요.

    파일에는 파일 이름과 좌표는 빠지지만 도면에 적힌 치수·글자는 들어가요. 올리면 팀원과 Microsoft 서비스에서 볼 수 있으니, 공개해도 되는 도면만 체크하세요.

      기존 결과 직접 입력 (시험용)

      이미 받은 ② 분석 결과 또는 ③ 검토 결과의 JSON을 붙여 넣으세요. 원본 도면과 같은 결과인지 직접 확인해 주세요.

      직접 입력한 내용은 자동 저장되거나 전송되지 않아요. 아래 저장 버튼을 눌렀을 때만 이 브라우저에 보관돼요. 처음으로 돌아가거나 도면을 다시 선택하면 입력과 결과가 지워져요. ② 가상 예제 JSON · ③ JSON 틀

      검토 에이전트용 자료 (DXF)

      위에서 읽은 선·원·글자를 Copilot Studio의 ③ 도면 검토 에이전트가 읽을 수 있는 글(JSON)로 바꿨어요. 원본 DXF 파일은 바꾸지 않아요. ②의 전체 분석을 한 것은 아니어서 “부분 완료”로 표시하고, 못 읽었거나 글자·위치가 불확실한 부분은 “확인 필요”로 남겨요.

      이 버튼은 자료를 복사만 하고 어디에도 보내지 않아요. 복사한 내용을 Copilot Studio에 붙여넣으면 파일 이름, 도면의 글자와 좌표가 외부 서비스(Microsoft Copilot Studio)로 전달돼요. 붙여넣기 전에 개인정보나 기밀이 없는지 확인해 주세요.

      읽은 요소만 다시 그린 미리보기예요. 원본의 글꼴·정렬·잘림·숨김 표시는 반영하지 않아요. 노란 글자와 점선 요소는 원본 확인이 필요해요.

      고칠 곳 안내

      원본 도면과 비교해 확인할 곳을 번호로 알려드려요. 번호를 누르면 도면에서 위치가 강조돼요.

      안내
      확인이 필요한 곳이 없어요

      읽은 요소 모두 파일에서 직접 읽었어요. 도면이 설계 기준에 맞는지는 판단하지 않아요.
